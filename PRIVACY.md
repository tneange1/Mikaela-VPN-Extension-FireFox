# Политика конфиденциальности расширения Mikaela VPN / Privacy Policy

Дата вступления в силу / Effective: 20.11.2026

## Русский

**Что делает расширение.** Mikaela VPN направляет трафик браузера через прокси-серверы Mikaela VPN, когда вы нажимаете кнопку включения.

**Какие данные хранятся в браузере.** Только выбранный сервер, состояние (включено/выключено) и кэш списка серверов. Данные хранятся локально в `chrome.storage` и не передаются нам.

**Что расширение не делает.** Оно не собирает и не отправляет вашу историю посещений, содержимое страниц, пароли, платёжные данные, cookies и личную информацию. Расширение не использует аналитику, рекламные сети и трекеры. Оно не загружает и не выполняет удалённый код: с сервера загружается только список серверов в формате JSON.

**Что видит прокси-сервер.** Пока VPN включён, запросы браузера проходят через сервер Mikaela VPN, поэтому сервер технически видит IP-адрес и адреса запрашиваемых узлов. Содержимое HTTPS-страниц сервер прочитать не может. Мы не продаём и не передаём эти данные третьим лицам и не используем их для рекламы. Технические данные соединений обрабатываются только для работы и защиты сервиса от злоупотреблений и хранятся не дольше, чем это необходимо.

**Учётные данные прокси.** Логин и пароль прокси-сервера, входящие в список серверов, используются расширением только для проверки подлинности на самом прокси-сервере.

**Как отключить.** Нажмите кнопку включения ещё раз или удалите расширение: настройки прокси браузера вернутся к исходным.

## English

**What the extension does.** Mikaela VPN routes your browser traffic through Mikaela VPN proxy servers when you press the power button.

**Data stored in your browser.** Only the selected server, the on/off state and a cached server list. It is stored locally in `chrome.storage` and is not sent to us.

**What it does not do.** It does not collect or transmit your browsing history, page content, passwords, payment data, cookies or personal information. It uses no analytics, ad networks or trackers. It does not download or run remote code; only a JSON list of servers is fetched.

**What the proxy server sees.** While the VPN is on, browser requests pass through a Mikaela VPN server, so the server can technically see your IP address and the hosts you connect to. It cannot read the content of HTTPS pages. We do not sell or share this data with third parties and do not use it for advertising. Technical connection data is processed only to operate the service and protect it from abuse, and kept no longer than necessary.

**Proxy credentials.** The proxy username and password included in the server list are used only to authenticate with the proxy server itself.

**How to stop.** Press the power button again or remove the extension: the browser proxy settings return to their previous state.
